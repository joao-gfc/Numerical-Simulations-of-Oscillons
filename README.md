# Numerical Simulations of Oscillons

Python, Julia, and C++ code developed by the Soliton Group in Pernambuco and collaborators for oscillon simulations.



The sphaleron\_profiles\_scan.cpp file computes the sphaleron profiles.



The spectrum\_sphaleron\_scan\_I.cpp file computes the sphaleron linearized spectrum.



The Julia notebook "Rapidly-collapsing-bubbles-radial.ipynb" computes the time evolution of a rapidly collapsing sphaleron according the radial equation. We achieve a rapid colapse by exciting the unstable sphaleron mode.



The "Rapidly-collapsing-bubbles\_2D.ipynb" and "Rapidly-collapsing-bubbles\_3D.ipynb" compute the time evolution of a rapidly collapsing sphaleron in the two-dimensional or three-dimensional space.



More information can be found in the ArXiV preprint (will be added soon).
